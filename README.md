# SportsShop
This Java program simulates a virtual sports shop, designed to manage product inventory and generate purchase receipts.

Key Features:
-Default Stock: The shop starts with a default inventory of twenty products.
Inventory Management:
Add new products to the stock.
Remove existing products from the stock.
Order products in stock by their ID.
Purchase Orders: The PurchaseOrder class handles purchase orders, adding products to an ArrayList.
Product Class: Products are created with specific attributes such as name, price, and ID.
Receipt Generation: The ShopTest class, located in the test package, demonstrates the program's functionality and generates purchase receipts.
Receipt Storage: Generated receipts are stored in the generated_receipts folder within the project directory.
